== 0.2.0 (3 mai 2026)

=== Ajouté

* `LoadEnv.load` émet désormais une ligne `INFO` à chaque chargement
  réussi : chemin résolu (absolu), nombre de variables posées, nombre
  ignorées (déjà présentes dans `ENV` ou skippées par `overwrite: false`).
  *Ni clés ni valeurs* — pas de fuite de secret dans les journaux.
* Une ligne `WARN` est émise quand le chemin demandé n'existe pas
  (avant : silence total). Pratique pour repérer un mauvais cwd ou un
  `.env` oublié — cas vécu : un wrapper rc.d qui ne fait pas `cd` avant
  d'`exec` le binaire, le `.env` est invisible et l'app retombe sur les
  défauts sans rien dire.
* Nouveau paramètre `quiet: Bool = false` sur `load` pour couper tous
  les logs (utile en tests ou pour les chargements multiples
  consécutifs où le bruit n'apporte rien).

=== Migration depuis 0.1.x

Aucun changement de comportement runtime. Si vous utilisiez `LoadEnv`
dans un test et que la sortie de log vous gêne, passez `quiet: true`.

== 0.1.0 (20 avril 2026)

=== Ajouté

* `LoadEnv.load(path = ".env", overwrite = false)` : charge un fichier
  `.env` dans `ENV`. Silencieux si le fichier est absent. Préserve par
  défaut les variables déjà exportées (convention : le shell l'emporte
  sur le fichier).
* `LoadEnv.parse(content)` : parse un contenu `.env` en
  `Hash(String, String)` sans toucher `ENV` (utile en tests).
* Parse les formats `KEY=VALUE`, `KEY="..."` (avec déséchappement
  bash-like `\n`, `\r`, `\t`, `\"`, `\\`), `KEY='...'` (littéral),
  `export KEY=...`. Ignore les commentaires `#` et les lignes vides.
* Sur valeurs non quotées, retire un commentaire de fin de ligne
  précédé d'un espace (`FOO=bar # note`).
* CI GitHub Actions : format + specs Linux et FreeBSD 15.
